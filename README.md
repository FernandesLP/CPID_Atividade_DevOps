## Visão Geral
Solução completa para monitoramento da qualidade do ar:
- **Backend API**: Python para processar dados de sensores
- **Frontend Web**: Vue.js para visualização interativa
- **Database**: MySQL com dados pré-carregados

## Pré-requisitos
- Docker
- Docker Compose
